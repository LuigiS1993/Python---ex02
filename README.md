# Desafio 2

Exercícios básicos de Python para praticar entrada de dados, strings e operações aritméticas.

## Exercícios

- `ex01.py`: solicita o nome e a idade do usuário e exibe os dados informados.
- `ex02.py`: recebe dois números inteiros, calcula a soma e mostra o resultado.
- `ex03.py`: demonstra operações com números, incluindo multiplicação, soma, subtração, divisão, divisão inteira e resto da divisão.

## Pré-requisitos

É necessário ter o Python 3 instalado.

## Como executar

Abra o terminal na pasta do projeto e execute um dos arquivos:

```powershell
python ex01.py
python ex02.py
python ex03.py
```
